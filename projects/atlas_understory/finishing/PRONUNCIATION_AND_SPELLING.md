# Spelling and pronunciation locks

The narration is recorded and is correct. Captions follow the **script's** spelling, character for character.
This table exists because ASR will drift on these words and because an "autocorrect" on any of them would introduce
an error into a documentary about evidence.

| Caption must read | ASR will often produce | Note |
|---|---|---|
| Alexandria’s | Alexandrias / Alexandria's | keep the curly apostrophe |
| Antirhodos | anti rodos, Anterodos, Antirodos | one word |
| Pharos | Pharaoh’s, Faros | the lighthouse, not a king |
| Isis Pharia | Isis Feria, Iris Faria | two words |
| Hadrian’s | Hadrians, Adrian's | |
| Shahr-i Qumis | Shahri Qumis, Shari Kumis | hyphens and lower-case `i` |
| Hecatompylos | Hecatompilos, Hecatompylus | |
| Goddio | Godio | Franck Goddio |
| Margaret Miles | Margret Miles | |
| UA.News | UA News | period, no space |
| Live Science | LiveScience | two words |
| UNESCO | Unesco | all caps |
| bulla | bulls, boola | |
| ring-signet | ring signet | hyphen kept |
| multibeam bathymetry | multi-beam bathymetry | one word |
| side-scan sonar | sidescan sonar | hyphen kept |
| amuletic | amuletik | |
| in situ | insitu, in-situ | two words, no hyphen |
| copper-alloy | copper alloy | hyphen kept |
| Parthian | Parthean | |
| second century AD | 2nd century AD | the script spells it out; keep it spelled out |
| AD one thirty-three to one thirty-four | AD 133–134 | the voice says words, the caption says words |
| October seventh, twenty twenty-six | October 7, 2026 | keep the spoken form |

**The rule behind the table:** a caption is a transcript, not a summary. If the voice says a number as words, the
caption says the words. If the script writes `may`, the caption does not write `might`. If the script writes
`Alexandria’s`, the caption does not write `Alexandria's`.
